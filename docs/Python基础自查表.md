## 第一档：现在就必须会，否则读不动代码

| # | 语法点 | 项目里在哪 | 一句话说明 |
| --- | --- | --- | --- |
| 1 | **切片** `seq[a:b]`、负数索引 | `chunking.py` 的 `buffer[-overlap:]`、`paragraph[start:start+size]` | `-1` 是最后一个，`[-80:]` 是最后 80 个元素；`[::-1]` 是反转 |
| 2 | **字符串方法** `strip` / `split` / `replace` | `chunking.normalize` | 去空白、按分隔符切开、替换；注意 `split` 不传参数 = 按任意空白切 |
| 3 | **函数默认参数** 与**关键字传参** | `split_text(text, size=500, overlap=80)` | 调用时可以只传想改的那个：`split_text(t, size=300)` |
| 4 | **`if` / `for` / `while` + `break`** | `_split_long_paragraph` 的滑动窗口 | `break` 立刻跳出循环，后面不执行 |
| 5 | **f-string** | `main.py` 的 `f"目前只支持这些格式：{...}"` | 字符串前面加 `f`，花括号里可以直接写表达式 |
| 6 | **生成器表达式** 与 `sum` | `retrieval.cosine_similarity` 的 `sum(a * b for a, b in zip(...))` | 括号里不建列表，边算边加，省内存 |
| 7 | **列表推导式** | `embeddings` 的 `[value / norm for value in vector]` | `[对每个元素做什么 for 元素 in 序列 if 条件]` |
| 8 | **`class` / `__init__` / `self`** | `db.Repository`、`embeddings.HashingEmbedder` | `self.x = 1` 是"这个对象自己的属性"；`__init__` 是创建对象时自动跑的函数 |
| 9 | **`@dataclass`** | `config.Settings`、`retrieval.Hit` | 装饰器帮你自动生成 `__init__`，你只写字段名和默认值 |
| 10 | **类型注解** `list[float]`、`str \| None`、`Sequence[str]` | 几乎每个函数签名 | 只是给人看的说明书，**运行时不检查**，写错了不会报错 |
| 11 | **`import` 与相对导入** `from .chunking import split_text` | `main.py` 开头 | 前面那个点表示"同级的包"，所以 `app/` 必须是一个包（有 `__init__.py`） |
| 12 | **`try` / `except` / `raise`** | `config._env_int`、上传时的 `raw.decode()` | 出错时不要让程序崩，转成一句人话；`raise ... from None` 是"不要把原始异常一起打印" |
| 13 | **`with` 与上下文管理器** | `db.Repository.connection` | 进 `with` 时准备资源（开连接），离开时自动收尾（提交/回滚/关闭），**哪怕中途报错也会执行** |
| 14 | **闭包**（函数里引用外面的变量） | `main.create_app` 里的 `ingest()` 用了外面的 `repo`、`embedder`、`settings` | 内层函数"记住"了外层函数的变量，不需要当参数传 |
| 15 | **`Protocol`**（结构化类型） | `embeddings.Embedder` | 不要求继承，只要"长得像"就行——所以换 embedding 模型时上层代码不用改 |

## 每天 20 分钟怎么补

1. **就地查，不要另开一本书**。读代码卡住 → 搜这 15 条里的对应条目 → 5 分钟内回到代码。
2. **在 `NOTES.md` 记一行**，格式：`buffer[-80:] → 取最后 80 个字符（负数索引从右往左）`。攒够十行就是你的专属速查表。
3. **验证"真懂"的标准不是"看懂了"，是"改一处还不坏"**：
   - 把 `split_text(text, size=500)` 改成 `size=300`，跑 `pytest`，看哪些测试挂了
   - 能在 `NOTES.md` 里写清"为什么挂"，这条就算过关
4. **不要背**。忘了就查第二次、第三次。查到第五次自然就记住了。

## 什么时候该停下来集中补

只有一种情况：**连续两天，每次读代码都卡在同一类问题上**（比如完全看不懂类和 `self`）。

那时停下来 2–3 天，只补这一块：Python 官方教程的「类」那一章 + 手写三个小类（比如一个 `BankAccount`），够了。补完立刻回来，别顺势"顺便把整本书看完"——那是拖延的伪装。
